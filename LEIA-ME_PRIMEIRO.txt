    http://127.0.0.1:5000

  O QUE MUDOU?
═══════════════════════════════════════════════════════════════════

ANTES (Snap7):
  - python app.py

AGORA (Nodes7) - MAIS SIMPLES:
  - .\start.ps1

O sistema:
  ✅ Detecta automaticamente a máquina pela rede
  ✅ Inicia o servidor Node.js (comunicação com PLC)
  ✅ Inicia a aplicação Flask (interface web)

Se algo não funcionar:

  1. Verifique se Node.js está instalado:

  3. Execute o teste:
     python test_nodes7_connection.py

  4. Consulte COMANDOS_UTEIS.md para mais ajuda


═══════════════════════════════════════════════════════════════════
  REVERTER PARA SNAP7 (se necessário)
═══════════════════════════════════════════════════════════════════

Se precisar voltar para Snap7 temporariamente:

  1. Edite app\data\machines_config.json
  2. Mude "plc_type": "nodes7" para "plc_type": "siemens_s7"
  3. Reinicie: python app.py

Você pode voltar para Nodes7 a qualquer momento invertendo o processo.
