================================================================================
                           TESTE RÁPIDO
================================================================================

Execute estes comandos para testar:

1. Teste conectividade de rede:
   ping 100.70.0.10

2. Teste porta 102 (Snap7):
   telnet 100.70.0.10 102
   # ou no PowerShell:
   Test-NetConnection -ComputerName 100.70.0.10 -Port 102

3. Inicie DataHub:
   python datahub.py

4. Verifique status:
   Abra: http://localhost:8000/api/status
   
   Deve retornar:
   {
     "connected": true,
     "machine_name": "700CX",
     "machine_ip": "100.70.0.10",
     ...
   }
