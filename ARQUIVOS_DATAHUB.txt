================================================================================
                        ESTRUTURA DO DATAHUB.PY
================================================================================

datahub.py contém:

1. Configurações
   - Lista de PLCs
   - DBs a ler
   - Timing

2. Funções Auxiliares
   - ping_ip() - Testa conectividade
   - detect_active_plc() - Detecta PLC ativo

3. Classe Snap7Handler
   - Gerencia conexão Snap7
   - read_db() - Lê bloco de dados
   - write_db() - Escreve dados
   - Reconexão automática

4. Classe DataHub
   - Cache de dados
   - Loop de leitura cíclica
   - Detecção de mudanças
   - Gerenciamento de WebSockets

5. FastAPI Application
   - GET /api/status - Status
   - GET /api/data - Todos os dados
   - GET /api/data/{db} - DB específica
   - POST /api/write/{db} - Escrever
   - WS /ws/alarms - WebSocket

6. Funções de Integração
   - get_data() - Para importar em outro código
   - get_status_dict() - Para importar em outro código

7. Main
   - Inicia servidor uvicorn
   - Gerencia lifecycle


================================================================================
                        PROBLEMAS COMUNS
================================================================================

❌ "Nenhum PLC respondeu ao ping"
   → Verifique se PLCs estão ligados
   → Teste: ping 100.40.0.10
   → Verifique firewall/rede

❌ "ModuleNotFoundError: No module named 'snap7'"
   → Execute: pip install -r requirements_datahub.txt

❌ "Erro ao ler DB"
   → Confirme que DBs existem no PLC
   → Verifique rack/slot (geralmente 0/1)
   → Habilite GET/PUT no PLC

❌ "Address already in use"
   → Porta 8000 já está em uso
   → Mude a porta no datahub.py
   → Ou pare o outro serviço

================================================================================
                        CARACTERÍSTICAS TÉCNICAS
================================================================================

Linguagem: Python 3.8+
Framework: FastAPI + Uvicorn
Protocolo PLC: Snap7 (Siemens S7)
APIs: REST + WebSocket
Formato dados: JSON

Dependências:
  - python-snap7==1.3
  - fastapi==0.109.0
  - uvicorn==0.27.0
  - pydantic==2.5.3

Performance típica:
  - Latência: ~50ms por leitura
  - Taxa: 5 ciclos/segundo
  - Memória: ~50MB
  - CPU: <5%
