================================================================================
                    📱 COMO SUAS TELAS USAM O DATAHUB
================================================================================

Você NÃO precisa mudar seu app.py imediatamente!

Suas telas HTML podem buscar dados diretamente do DataHub:

JAVASCRIPT (nas suas telas):
────────────────────────────────────────────────────────────────────────────

// Buscar status do PLC
fetch('http://localhost:8000/api/status')
    .then(res => res.json())
    .then(data => {
        console.log('Conectado:', data.connected);
        console.log('Máquina:', data.machine_name);
    });

// Buscar dados da DB1
fetch('http://localhost:8000/api/data/1')
    .then(res => res.json())
    .then(data => {
        const dbData = data.db.data;  // Array de bytes
        console.log('Dados:', dbData);
    });

// WebSocket para tempo real
const ws = new WebSocket('ws://localhost:8000/ws/alarms');
ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    if (data.type === 'alarm_changes') {
        console.log('Mudanças:', data.changes);
    }
};


OU PYTHON (no seu app.py):
────────────────────────────────────────────────────────────────────────────

import requests

# Buscar status
response = requests.get('http://localhost:8000/api/status')
status = response.json()

# Buscar dados
response = requests.get('http://localhost:8000/api/data/1')
dados = response.json()['db']['data']

────────────────────────────────────────────────────────────────────────────
SOLUÇÃO:
   1. Verifique se DataHub está rodando
   2. Abra console do navegador (F12)
   3. Veja se há erros CORS

PROBLEMA: Porta 8000 já está em uso
────────────────────────────────────────────────────────────────────────────
SOLUÇÃO:
   Edite datahub.py linha ~800:
   port=8001  # mude de 8000 para 8001


================================================================================
                        📊 ENDPOINTS DISPONÍVEIS
================================================================================

GET /api/status
   → Status da conexão com PLC
   Retorna: {connected, machine_name, machine_ip, ...}

GET /api/data
   → Todos os dados em cache
   Retorna: {timestamp, data: {db1: {...}, db2: {...}}}

GET /api/data/1
   → Dados da DB1 especificamente
   Retorna: {timestamp, db: {db, size, data}}

POST /api/write/1?offset=10&value=255
   → Escreve byte no PLC
   Retorna: {success, message}

WS /ws/alarms
   → WebSocket para notificações em tempo real
   Envia: {type: 'alarm_changes', changes: [...]}

            .then(res => res.json())

                    data.connected ? '✅ Online' : '❌ Offline';

    }, 1000);
</script>


USAR NO SEU APP.PY:
────────────────────────────────────────────────────────────────────────────
from flask import Flask, jsonify
import requests

app = Flask(__name__)

@app.route('/api/plc/dados')
def get_dados():
    response = requests.get('http://localhost:8000/api/data/1')
    return jsonify(response.json())
